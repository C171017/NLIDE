# Users

## Primary users

Solo builders and small teams who want to clarify intent visually before delegating implementation to AI agents.

## Personas

- **Solo builder** — defines features on the canvas, exports spec, hands off to Cursor or other agents
- **Small team lead** — keeps shared intent aligned before agent sprints

## Pain points

- Natural language intent scattered across chats and notes
- Agents guess scope without acceptance criteria
- Hard to see how features, tasks, and architecture connect

## Use cases

- Describe a feature in chat → review structured spec preview → commit → export for external agents
- Pan/zoom the intent canvas to read the whole project on overview
